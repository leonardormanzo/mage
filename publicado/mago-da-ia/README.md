# Mago da IA

Landing page da marca pessoal Mago da IA, voltada a apresentar aplicações práticas de
inteligência artificial e automação para construção civil.

## Demonstração

Abra `index.html` para visualizar a página estática. Esta versão é uma demonstração de
posicionamento e interface: não possui formulário conectado, autenticação, backend ou
integrações de IA em produção.

## Publicação

O arquivo é autocontido e pode ser servido diretamente por GitHub Pages, Cloudflare
Workers ou qualquer servidor de arquivos estáticos.
